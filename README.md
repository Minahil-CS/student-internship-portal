# InternFlow — Student Internship Portal

A responsive, single-file frontend web application built with **HTML5**, **CSS3**, and **Vanilla JavaScript** that lets students browse internship opportunities, inspect detailed role expectations, save roles, submit applications, and track application stages with `localStorage` persistence.

## Features

- **Explore & Multi-Criteria Filtering:** Search in real time by role, company, or skill, and filter by domain (`Software Engineering`, `AI & Data Science`, `UI/UX Design`, `Cloud & DevOps`) and work mode (`Remote`, `Hybrid`, `On-site`).
- **Saved Internships View:** Bookmark roles for quick access with live badge counters in the navigation bar.
- **Role Details Modal:** View complete role descriptions, key responsibilities, eligibility criteria, stipend, duration, and deadlines.
- **Application Submission Flow:** Apply through a validated modal form with duplicate-application protection and toast notifications.
- **Application Pipeline Tracker:** Monitor submitted applications across a 4-stage stepper (`Submitted` → `Under Review` → `Interview` → `Offered`), view summary metrics, simulate stage progression, or withdraw applications.

## Tech Stack

- **Markup & Styling:** HTML5, Custom CSS3 (CSS Variables, Flexbox, Grid, Glassmorphism/Sticky Nav, Responsive Media Queries)
- **Scripting & State:** Vanilla JavaScript (ES6+), Browser `localStorage`
- **Icons & Typography:** Font Awesome 6, Google Fonts (`Inter`)
